# YouTube Live

**A streamer kit for coding live on YouTube: chat overlay, viewer ideas, points, slots and polls.**

*Optional — install from Settings → Plugins.*

Reads your stream's live chat and turns it into an on-stream overlay. Viewers suggest features with
`!idea`, which you can promote straight into the project's Issues; they earn points by chatting and
spend them on a slot machine. Polls, alerts, leaderboards and spoken announcements round it off.

## Features

- **Overlay tabs**: Goals, Ideas, Slots, Leaderboard, Messages, Subscribers, Polls and How to Earn,
  with optional auto-cycling between tabs.
- **Viewer ideas**: `!idea <text>` (prefix configurable) captures an idea; promote it to a QuadFlow
  issue in the current project, or dismiss or hide it. Ideas and approvals can award points.
- **Points and chat XP**: a starting balance, points per chat message (with cooldown), rewards for
  submitted and approved ideas.
- **Slot machine**: `!pull` (configurable) spends points; editable symbols with weights, a pay table,
  progressive jackpot, symbol of the day, lucky hour and a prize log.
- **Live polls**: native YouTube polls, manual or auto-generated by an AI model from the chat.
- **Alerts**: Super Chats, Super Stickers, new members, gifted memberships, milestones and new
  subscribers.
- **Spoken announcements** (OpenAI text-to-speech) for new ideas (name only or the full idea),
  alerts and polls.
- **Video and channel stats**, an API quota meter and adaptive polling that slows down when chat is
  quiet.

## Setup

The overlay needs a **YouTube Data API key**; everything else is optional.

| What | Needed for | Where to get it |
|---|---|---|
| YouTube Data API v3 key | Reading chat, stream search, stats | Google Cloud Console → Credentials → API keys (enable *YouTube Data API v3*) |
| OAuth client ID + secret | Subscriber notifications, posting live polls | Google Cloud Console → Credentials → OAuth client ID |
| OpenAI API key | Text-to-speech, AI-generated polls | platform.openai.com |

1. Save the API key in a JSON file, `{ "key": "AIza..." }` (a plain-text file with just the key also
   works), and choose it under **YouTube Live Settings → Connection → API Credentials**. OAuth
   client-secret and service-account files are rejected with an explanation.
2. Optionally set a default channel ID (`UC…`), then **Connect to Live Stream**: it finds your live
   streams, or paste a video URL or ID.
3. For OAuth, enter the client ID and secret on the **OAuth** tab and start the sign-in. The browser
   opens Google's consent page and redirects back to a temporary `http://127.0.0.1:<port>` listener
   (a *Desktop app* OAuth client allows this). Scopes: `youtube.readonly` (subscribers) and
   `youtube.force-ssl` (posting polls).
4. For voice and AI polls, enter the OpenAI key on the **AI & Voice** tab (defaults: voice `alloy`,
   TTS model `tts-1`, chat model `gpt-4o-mini`).

The settings tile shows masked credentials, but keep it off stream.

## Usage

| Command | What it does |
|---|---|
| YouTube Live: Open Chat Overlay | Opens the overlay tile |
| YouTube Live: Settings | Opens the settings tile |
| YouTube Live: Simulate Chat Idea | Test an idea without a stream |
| YouTube Live: Simulate Slot Pull | Test the slot machine |
| YouTube Live: Simulate Alert | Test an alert |
| YouTube Live: Simulate Subscriber | Test a subscriber notification |

Both tiles open as a pane or a flyout. The settings tile has tabs for Connection, Features,
Commands, Points, Slots, Display, API & Stats, OAuth, Polls and AI & Voice. The daily API quota
defaults to 10,000 units with a warning at 80%.

## Permissions

| Permission | Why |
|---|---|
| `secrets` | API key, OAuth client and tokens, OpenAI key in the OS keychain |
| `network:www.googleapis.com` | YouTube Data API |
| `network:oauth2.googleapis.com` | OAuth token exchange and refresh |
| `network:api.openai.com` | Text-to-speech and AI-generated polls |
| `data:issues:write` | Promote viewer ideas to issues |
| `shell:open-external` | Open the OAuth consent page in the browser |

## Data

- Secrets (API key, OAuth client ID/secret and tokens, OpenAI key): the OS keychain.
- Everything else (settings, viewers and points, ideas, slots, polls, streams, quota usage):
  `youtube_live.db` (SQLite) in the plugin data folder, `<QuadFlow data>/plugin-data/youtube-live/`.

## Development

```bash
cd plugins/youtube-live
npm run build       # UI module + release sidecar → bin/
npm run build:ui    # UI module only
npm run pack        # release archive (see docs/plugins/publishing.md)
```

- `src/LiveTile.tsx`, `src/SlotMachine.tsx` — the overlay
- `src/SettingsTile.tsx` — the settings tile
- `src/store.ts`, `src/api.ts`, `src/bridge.ts` — Zustand store and sidecar calls
- `sidecar/src/` — Rust sidecar: chat poller, YouTube API, OAuth, slots, OpenAI calls, SQLite
  (`db/`)

The GUI e2e test is `scripts/ui/youtube-live.test.mjs`. Sidecars:
[docs/plugins/sidecars.md](../../docs/plugins/sidecars.md); publishing:
[docs/plugins/publishing.md](../../docs/plugins/publishing.md).
